NIX-BUILDS نسخه اصلاح‌شده

فایل‌ها:
- _worker.js : در پروژه Cloudflare جایگزین Worker فعلی شود.
- index.html : جایگزین index فعلی شود.

تغییرات: دامنه اصلی nixbuilds.ir در canonical و sitemap؛ سایت‌مپ XML استاندارد؛ بهبود Product structured data در صورت وجود قیمت واقعی؛ فیلتر موجودی؛ توضیحات اختیاری سفارش در پیامک؛ نمایش دوخطی لاین‌ها در موبایل؛ افزودن NIX-AUTO و NIX-CUSTOM به صفحه درباره ما.

نکته: بخش دیدگاه کاربران اضافه نشده است؛ گرفتن نام و شماره موبایل به‌تنهایی احراز هویت امن نیست و برای پیاده‌سازی واقعی باید جدول Supabase، سیاست‌های RLS، تأیید شماره/OTP و مدیریت گزارش/حذف دیدگاه تنظیم شود. این کار بدون راه‌اندازی سمت سرور امن می‌تواند اسپم و سوءاستفاده ایجاد کند.

پس از انتشار: در مرورگر این آدرس‌ها را باز کنید: https://nixbuilds.ir/sitemap.xml و https://nixbuilds.ir/robots.txt . سپس در Google Search Console دامنه nixbuilds.ir > Sitemaps آدرس sitemap.xml را ثبت کنید. در URL Inspection برای محصولات جدید Request Indexing بزنید. ایندکس شدن فوری تضمین نمی‌شود.
